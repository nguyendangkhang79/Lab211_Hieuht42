J1.S.P0006 - Binary Search Algorithm

Yêu cầu bài:
- Nhập số lượng phần tử của mảng (số nguyên dương).
- Sinh ngẫu nhiên các số nguyên trong phạm vi từ 0 đến size - 1.
- Nhập giá trị cần tìm.
- Sắp xếp mảng tăng dần.
- Hiển thị mảng sau khi sắp xếp.
- Tìm giá trị bằng thuật toán Binary Search.
- In index nếu tìm thấy; thông báo nếu không tìm thấy.

Cách chạy:
1. Mở project bằng IDE Java, hoặc
2. Từ thư mục J1.S.P0006 chạy:

   javac -d out src/j1/s/p0006/Main.java
   java -cp out j1.s.p0006.Main

Ghi chú:
- Binary Search chỉ hoạt động đúng khi mảng đã được sắp xếp.
- binarySearch() được tự cài đặt theo thuật toán chia đôi khoảng tìm kiếm.
